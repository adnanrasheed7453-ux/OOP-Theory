# Student Constructor in C++

## 📌 Overview
This project demonstrates the use of constructors in C++ Object-Oriented Programming (OOP). It uses a `student` class to store and display student information such as name, CGPA, and age.

## 📚 Concepts Covered
- Classes and Objects
- Data Members
- Default Constructor
- Parameterized Constructor
- Constructor Overloading
- Member Functions
- Private and Public Access Specifiers

## ⚙️ Constructors Used
1. **Default Constructor:** Initializes the student with default values.
2. **Parameterized Constructor:** Initializes the student with a name, CGPA, and age.
3. **Single-Parameter Constructor:** Initializes the name and assigns default values to CGPA and age.

## 💻 Technologies Used
- C++
- Object-Oriented Programming (OOP)

## ▶️ Example
```cpp
student s1("HASAN");
```
